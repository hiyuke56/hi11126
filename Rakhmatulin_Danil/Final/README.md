# Итоговый ИИ-Агент: Репетитор по французскому языку
## Описание проекта
Данный проект представляет собой финального интеллектуального помощника, разработанного в рамках учебной практики
Помощник выступает в роли репетитора по французскому языку. Он использует технологию RAG, что позволяет ему отвечать на вопросы, опираясь не только на базовые знания нейросети GigaChat но и на подготовленную базу знаний (корпус документов)
## Как это работает
1. Пользователь вводит вопрос в консоль
2. Программа преобразует вопрос в вектор
3. Система ищет наиболее подходящие фрагменты в папке `chunks/`
4. Найденный контекст вместе с вопросом отправляется в GigaChat
5. Модель генерирует ответ опираясь на предоставленные материалы
## Структура проекта
- `final_agent.py` — основной файл программы (запуск чата).
- `chunks/` — папка с нормализованными текстовыми фрагментами (база знаний).
- `certs/` — папка с корневым сертификатом Минцифры для работы GigaChat.
- `.env` — файл с секретными ключами (не загружается на GitHub).
